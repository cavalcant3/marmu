# Story: API de Pedidos (CRUD + Vinculação)

## Context
Backend para gerenciar pedidos vinculados a orçamentos aprovados.

## Acceptance criteria
- [ ] `POST /pedidos` — cria pedido a partir de orçamento_id + data_entrega + observações
- [ ] `GET /pedidos` — lista pedidos do usuário (filtros: pendentes, entregues)
- [ ] `GET /pedidos/:id` — detalhes do pedido (com dados do orçamento)
- [ ] `PUT /pedidos/:id` — atualiza data ou observações
- [ ] `PUT /pedidos/:id/entregue` — marca como entregue
- [ ] Validação: orçamento deve existir e pertencer ao usuário

## Done means
- API testada
- Testes passam
