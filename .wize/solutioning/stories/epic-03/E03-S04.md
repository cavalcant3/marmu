# Story: Notificações Push Locais (Lembretes)

## Context
Agendar lembrete automático 2 dias antes do prazo de entrega.

## Acceptance criteria
- [ ] Notifee configurado no Android
- [ ] Ao criar pedido com data, agenda notificação para (data - 2 dias) às 08h
- [ ] Notificação exibe: "Pedido do [cliente] vence [data]"
- [ ] Tocar na notificação abre Detalhes do Pedido
- [ ] Se pedido entregue antes: cancela notificação
- [ ] Funciona offline (notificação local)

## Done means
- Notificação dispara corretamente
- Testes passam
