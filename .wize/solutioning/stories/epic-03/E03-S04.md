# Story: Notificações Push Locais (Lembretes)

## Context
Agendar lembrete automático 2 dias antes do prazo de entrega.

## Acceptance criteria
- [x] Notifee configurado no Android com canal de alta prioridade
- [x] Ao criar pedido com data, agenda notificação para (data - 2 dias) às 08h
- [x] Notificação exibe cliente e data combinada
- [x] Tocar na notificação abre Detalhes do Pedido
- [x] Se pedido entregue antes: cancela notificação
- [x] Funciona offline (notificação local)
- [x] Resumos operacionais às 06h, 12h e 17h
- [x] Compromissos da agenda são lembrados 30 minutos antes
- [x] Ações: lembrar em 30 minutos, reagendar/ver pedido e fechar definitivamente o aviso
- [x] Dispensa notificações já reconhecidas para não recriá-las em uma sincronização

## Done means
- Notificação dispara corretamente
- Testes passam
