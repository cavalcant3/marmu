# Story: Setup Expo e Estrutura Base do App Mobile

## Context
Scaffold do app React Native com Expo. Configurações iniciais, navegação, tema, fontes.

## Sources of truth
- `architecture.md` (Frontend Architecture section)
- `ux-design/index.md` (Decisões de design pendentes)

## Acceptance criteria
- [ ] Expo SDK 53+ inicializado com template blank
- [ ] TypeScript configurado (`strict: true`)
- [ ] Expo Router v3 configurado (file-system routing)
- [ ] Estrutura de pastas segue `architecture.md` (screens, components, hooks, stores, services, db, utils, types)
- [ ] Tema Material Design 3 configurado (cores, tipografia)
- [ ] Fonte Roboto carregada
- [ ] SQLite configurado (react-native-sqlite-storage)
- [ ] MMKV configurado
- [ ] NetInfo configurado
- [ ] Build funciona: `npx expo start`

## Restrictions
- **Out of scope:** dark mode, animações complexas
- **Protected:** nenhum
- **Compatibility:** Android SDK 24+

## Notes for Shuri (Dev)
- `npx create-expo-app@latest marmu-app --template blank`
- Instalar dependências: expo-router, zustand, tanstack-query, react-native-sqlite-storage, react-native-mmkv, @react-native-community/netinfo
- Configurar `app.json` com nome, ícone, splash screen

## Validation contract
- **Testes:** app sobe sem erros (`npx expo start`)
- **Checks:** TypeScript compila (`tsc --noEmit`)

## Done means
- `npx expo start` roda o app no Android
- Estrutura de pastas criada
- README com instruções de setup
