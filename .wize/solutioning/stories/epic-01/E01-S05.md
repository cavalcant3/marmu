# Story: Tela de Login no App Mobile

## Context
Primeira tela que o gestor vê ao abrir o app. Simples, rápida, funciona offline (mostra erro se tentar logar sem internet).

## Sources of truth
- `architecture.md` (Frontend Architecture section)
- `ux-design/Login.tsx` (a criar)

## Acceptance criteria
- [ ] Tela com campos: email, senha, botão "Entrar"
- [ ] Validação: email válido, senha ≥ 6 caracteres
- [ ] Chamada à API `POST /auth/login`
- [ ] Sucesso: armazena tokens (access + refresh) no MMKV
- [ ] Erro: mensagem amigável ("Email ou senha incorretos")
- [ ] Loading state no botão durante chamada
- [ ] Link "Criar conta" → navega para tela de registro

## Restrictions
- **Out of scope:** registro (próxima story), recuperação de senha, biometria
- **Protected:** nenhum
- **Compatibility:** Android API 24+ (Android 7.0)
- **Security:** nunca logar token; senha não visível (password field)

## Notes for Shuri (Dev)
- Usar React Hook Form + Zod para validação
- Axios instance em `services/api.ts` com baseURL configurável
- MMKV para armazenar tokens (synchronous, encrypted)
- NetInfo para detectar offline

## Validation contract
- **Testes:**
  - Unit: validação de formulário (email inválido, senha curta)
  - Integration: login com mock de API
- **NFR:** tela carrega em ≤ 1s

## Done means
- Login funciona com usuário real da API
- Tokens persistem após fechar app
- Testes passam
