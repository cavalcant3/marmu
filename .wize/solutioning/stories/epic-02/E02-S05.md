# Story: Geração de PDF do Orçamento

## Context
Criar PDF profissional com todos os dados do orçamento para enviar ao cliente.

## Sources of truth
- `ux-design/visualizar-orcamento.md`
- `prd.md` (E03)

## Acceptance criteria
- [ ] PDF contém: nome da marmoaria, número do orçamento, data, cliente, descrição, medidas, área, material, preço final, validade
- [ ] Layout profissional (cabeçalho, separadores, alinhamento)
- [ ] Gerado no device (offline-capable)
- [ ] Salvo em `/Downloads/Marmu/`
- [ ] Preview do PDF na tela antes de compartilhar

## Restrictions
- **Out of scope:** múltiplos templates, assinatura digital
- **Protected:** nenhum

## Notes for Shuri (Dev)
- `react-native-html-to-pdf` (HTML → PDF nativo)
- Template HTML com CSS inline
- Nome do arquivo: `Orcamento_{id}_{cliente}_{data}.pdf`

## Validation contract
- **Testes:**
  - Unit: template HTML renderiza corretamente
  - Integration: PDF gerado com dados de exemplo
- **NFR:** geração ≤ 2s

## Done means
- PDF gerado e salvo no device
- Layout verificado visualmente
- Testes passam
