# Story: Tela "Novo Orçamento" (Formulário + Cálculo)

## Context
Tela mais crítica do app. Dono digita medidas e vê preço calculado em tempo real.

## Sources of truth
- `ux-design/novo-orcamento.md`
- `prd.md` (E01 — AC-01-1 a AC-01-5)

## Acceptance criteria
- [ ] Campos: cliente (opcional), comprimento, largura, material, observações
- [ ] Área calculada em tempo real: comprimento × largura (≤ 500ms)
- [ ] Preço sugerido: área × preço_por_m2 do material (≤ 500ms)
- [ ] Preço final: editável manualmente (sobrescreve sugerido)
- [ ] Offline-first: salva no SQLite local
- [ ] Validação: comprimento/largura > 0
- [ ] Se sem materiais cadastrados: modal "Cadastre materiais primeiro"

## Restrictions
- **Out of scope:** descontos. Múltiplas medições e itens adicionais foram trazidos para o escopo por decisão do usuário em 2026-08-01.
- **Protected:** nenhum
- **Compatibility:** teclado numérico decimal (vírgula e ponto)
- **Security:** nenhum dado sensível nesta tela

## Notes for Shuri (Dev)
- React Hook Form + Zod para validação
- Cálculo no componente (feedback instantâneo)
- MMKV cache de materiais para performance
- SQLite: salva rascunho automaticamente (auto-save)

## Validation contract
- **Testes:**
  - Unit: cálculo de área e preço
  - Unit: validação de campos
  - Integration: salvar orçamento offline no SQLite
- **NFR:** cálculo em ≤ 500ms; tela abre em ≤ 1s

## Done means
- Orçamento criado offline com todos os campos
- Cálculo correto testado com valores reais
- Testes passam

## Scope extension (2026-08-01)

- [x] Um orçamento aceita várias medições, cada uma com descrição, dimensões e quantidade.
- [x] Área total é a soma das áreas de todas as medições.
- [x] Usuário escolhe cálculo por metro quadrado ou metro linear.
- [x] Metro linear soma comprimento × quantidade e usa preço linear próprio do material.
- [x] Mão de obra e acabamentos são itens discriminados com valor próprio.
- [x] Total sugerido soma material, mão de obra e acabamentos.
- [x] Telefone, moeda, decimais e data usam máscaras pt-BR.
- [x] Conversão para pedido é idempotente na interface, store e serviço local.
- [ ] Persistir a nova composição na API/PostgreSQL; o schema atual suporta apenas uma medição.

## Responsive extension (2026-08-01)

- [x] Conteúdo centralizado e limitado a 720 px em tablets.
- [x] Espaçamento, navegação, cartões, listas e modais adaptados abaixo de 390 px.
- [x] Áreas clicáveis e cores permanecem dentro do design system existente.
