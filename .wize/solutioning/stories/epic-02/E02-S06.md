# Story: Compartilhamento via WhatsApp

## Context
Enviar o PDF diretamente pelo WhatsApp para o cliente.

## Sources of truth
- `ux-design/visualizar-orcamento.md`
- `prd.md` (E03)

## Acceptance criteria
- [ ] Botão "Enviar por WhatsApp" abre WhatsApp com contato
- [ ] PDF anexado automaticamente
- [ ] Texto pré-preenchido: "Olá [cliente], segue o orçamento da [marmoaria]. Total: R$ [valor]"
- [ ] Fallback: se WhatsApp não instalado, mostrar "Salvar PDF" + "Compartilhar via..."
- [ ] Funciona offline (PDF salvo localmente; envio quando WhatsApp abre)

## Restrictions
- **Out of scope:** envio automático (sem abrir WhatsApp), Telegram como primário
- **Protected:** nenhum

## Notes for Shuri (Dev)
- Android Intent: `ACTION_SEND` com tipo `application/pdf`
- `react-native-share` para fallback
- Permissão de armazenamento para acessar PDF

## Validation contract
- **Testes:**
  - Unit: intent montado corretamente
  - Integration: compartilhamento com mock de WhatsApp
- **NFR:** abertura do WhatsApp ≤ 1s

## Done means
- PDF enviado pelo WhatsApp (testado em device real)
- Fallback funciona
- Testes passam
